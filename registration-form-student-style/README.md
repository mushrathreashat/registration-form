# Registration Form

A basic Registration Form made for Web Technology practice using HTML and CSS.

## Files
- `index.html` - contains the form
- `style.css` - styles the form
- `output-preview.png` - preview of the design

## How to open
1. Extract the ZIP file.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in Chrome.

The form is a front-end practice task and does not store submitted information.
